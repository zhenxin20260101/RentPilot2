# 鎮信安東房客資格審查試算系統

一個專為租賃住宅社會住宅與租金補貼審查設計的前端試算工具。經辦人員可透過此系統輸入申請人及其家庭成員的各項所得與財產，快速判定是否符合特定縣市的承租資格。

## 💡 核心功能
* **多縣市標準切換**：內建桃園市、南投縣、彰化縣等現行所得與財產審查標準。
* **動態欄位增刪**：支援自由新增多筆家庭成員、收入、動產與不動產資料。
* **利息回推功能**：依現行郵政儲金利率自動將利息所得回推為動產本金。
* **響應式網頁設計 (RWD)**：支援手機與平板操作，第一線現勘同樣適用。
* **一鍵列印最佳化**：特殊排版隱藏操作按鈕，並於報表附帶自動資格判定印章。

## 🛠️ 開發架構
* **HTML5** - 結構排版
* **CSS3** - 包含 `@media print` 報表列印優化
* **Vanilla JavaScript** - 純原生邏輯控制，零外部相依性（無須安裝 npm / node）

## 🚀 如何使用
1. 將本專案 `clone` 或下載至本地端。
2. 直接雙擊 `index.html` 即可在瀏覽器中運行。
3. 或開啟 **GitHub Pages** 功能將其轉為線上工具。
